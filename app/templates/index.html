Import enriched candidate CSV

Select one or more supported U.S. candidate CSVs. Profession is detected from Headline first and PDL job title second; profiles without a confident profession match are excluded. Each accepted row is assigned to the state in its Location. The preview requires confidence 3+ when supplied, prefers personal email/mobile-phone columns, deduplicates contacts, and checks Nexus before creation.

Choose one or more CSVs, then run Preview. No records are created during preview.
