NEXUS RESUME UPLOADER - WINDOWS APP
===================================

1. Keep NexusUploader.exe and .env in the same folder.
2. Double-click NexusUploader.exe.
3. Wait for the browser to open the uploader.
4. Keep the black NexusUploader window open while using the app.
5. Press Ctrl+C in that window, or close it, to stop the app.

The app runs only on this computer at http://127.0.0.1. If the configured
port is busy or reserved, it automatically chooses the next available port.

IMPORTANT: .env contains private Nexus credentials. Do not email, upload, or
share this folder. If credentials change, edit .env and restart the app.

Windows may show a SmartScreen warning because this internal executable is
not code-signed. Use "More info" and "Run anyway" only if the executable came
from your trusted project folder.
